# 🧮 Day 1 – Smart Calculator | 20-Day Python Challenge

## 📌 About the Project

The **Smart Calculator** is a beginner-friendly Python project developed as part of my 20-Day Python Mini-Project Challenge. It performs basic mathematical calculations using user-inputted numbers and demonstrates fundamental Python programming concepts.

## 🚀 Features

- Addition
- Subtraction
- Multiplication
- Division
- User input for numbers
- Personalized greeting
- Simple command-line interface

## 🛠️ Technologies Used

- Python 3
- PyCharm
- Git & GitHub

## 📚 Python Concepts Learned

- Variables
- Data types (`int`, `float`, `str`)
- User input using `input()`
- Type conversion using `float()`
- Arithmetic operators
- Output using `print()`

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/simplelife277/Day_01_Smart_Calculator.git
```

2. Navigate to the project folder:

```bash
cd Day_01_Smart_Calculator
```

3. Run the Python file:

```bash
python smart_calculator.py
```
